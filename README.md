# Thunder Valley

A 3D browser game of dinosaurs on the frontier. Dustfork is a town under a gang's thumb: earn its trust, herd longhorns, tame a string of dinosaurs, build a posse and take the town for your own. Single player, 18 story quests with four endings.

**Play it now: https://ranjith-p-16.github.io/thunder-valley/**

It runs as plain files in the browser: no install and no build step. The code is MIT licensed and the models are public domain, so you are free to change it and share what you make.

## Play it locally

```bash
python3 serve.py 8911
```

Then open http://localhost:8911. The game needs a web server (it will not run from a `file://` address) and a browser with WebGL 2.

Add `?q=low` to the address to force low graphics, or `?q=high` to force high. Otherwise the Settings panel on the title screen decides.

## Put it online

```bash
node tools/build.mjs
```

This writes `dist/` (about 13 MB): upload that folder to any static host. Nothing in it needs a server-side language.

## Controls

The full list is on the title screen. The essentials: `WASD` ride, mouse aim, click fire, `Shift` sprint, `Space` mount ability, `Y` or right click for the second move, `V` strike, `T` tame, `B` next dinosaur, `F` talk or use a building, `M` map, `J` journal, `P` pause, `N` sound.

## Settings

Graphics quality, mouse sensitivity, inverted look, camera shake, text size, volume and a high-contrast map are in the Settings panel on the title and pause screen. They are stored in the browser, apart from the save.

## Saves

One save, stored in the browser and written automatically. Export and Import on the menu move it between browsers as a file.

## Layout

| Folder | What is in it |
|---|---|
| `src/sim` | The rules. No drawing and no browser APIs: runs in Node for the tests |
| `src/data` | Every number and every line of story |
| `src/render`, `src/ui`, `src/input`, `src/audio`, `src/save` | Drawing, screens, controls, sound, storage |
| `assets` | Models (see `CREDITS.md`) |
| `vendor/three` | three.js, vendored |
| `tests` | Scripted checks of the rules; `tests/playtest` holds testers' one-off scripts |
| `tools` | `build.mjs` (make `dist/`), `repack-nature.mjs` and `trim-glb.mjs` (shrink models) |

## Tests

```bash
npm test
```

Needs Node 18 or newer.

## Changing the game

Changes are welcome: fixes, balance, new quests, new animals, better art.

1. Fork the repository and clone your fork.
2. Run `python3 serve.py 8911` and open http://localhost:8911. Edit a file and reload: there is nothing to compile.
3. Run `npm test` before you send anything. The rules in `src/sim` run without a browser, so a rule change should come with a check in `tests/`.
4. Open a pull request that says what changed and how you tried it.

Where things are:

- **A number feels wrong** (damage, prices, speeds): `src/data/content.js`, `src/data/items.js`, `src/data/frontier.js`.
- **Story and dialogue**: `src/data/story.js`. Quests are data: steps, conversations and choices.
- **A new animal or mount**: add its numbers to `KINDS` or `MOUNTS` in `src/data/content.js` and its model to `ASSETS` in `src/render/assets.js`. Models are `.glb` files with clips ending in `_Idle`, `_Run`, `_Attack` and `_Death`.
- **How something looks**: `src/render`. **Menus and the display**: `src/ui` and `index.html`.

A few rules of the house:

- `src/sim` never touches the page or three.js. Drawing reads the rules' state; it does not change it.
- Art must be yours to give or under a licence that allows reuse (CC0 or CC-BY). Add it to `CREDITS.md`. Models ripped from other games will not be accepted.
- Found a bug but not fixing it? Open an issue with what you did, what happened and what you expected.

## Known gaps

- The story is short, and most quests are still "ride there, talk, fight, return".
- Balance has mostly been tuned by scripts, not by people playing.
- Three planned animals (a flyer, an armoured one, a spinosaur) have no models yet.
- Sound is generated by code; there is no recorded music.
